# /auto-goo:goo-subagent — subagent 实时活动

派发 subagent 后，**它在做什么**以前只能从工具输出的滚屏里瞥一眼（还容易被刷掉）。
现在把活动记录到内存，随时用面板回看：

```text
/goo-subagent      # 打开完整面板
```

或按 **`alt+a`**（`ctrl+*` 基本被 pi 内置键位占满，故用 `alt+a`）。

> 早期版本还额外用 `ctx.ui.setWidget` 在状态栏下面常驻显示多行活动，
> 但用户反馈与既有状态栏重复、太吵，已移除 —— 只保留按需打开的面板。

## 用法

```text
/goo-subagent      # 打开完整面板
```

或按 **`alt+a`**（`ctrl+*` 基本被 pi 内置键位占满，故用 `alt+a`）。

## widget（状态栏下面）

```
● subagent 运行中（2）
  ► #1 implementer/feature-builder
    💬 我先看一下 locks.ts
    ⚙ ⟦read: src/utils/locks.ts⟧
    ↳ ⟦result⟧ 120 lines
  ► #2 evaluator
    ⚙ ⟦grep: TODO in src/⟧
```

- 只列**运行中**的 step；全部结束后显示「最近一次」的最后状态
- 事件图标：`💬` 模型文本 · `⚙` 工具调用（**带真实参数**）· `↳` 工具结果
- 每次活动推送即重绘（`activityBus` 直接调用 `tui.requestRender()`，不轮询）

## 面板

```
────────────────────────────────────────────────────────────────
 ◆ AutoGoo Subagent                    2 运行中 · 2 step · 03:12
────────────────────────────────────────────────────────────────
 ▸ 步骤　(1/2)
 › ► #1    implementer/feature-builder   running    02:14
     └ ⟦bash: npm test -- locks⟧
   ► #2    evaluator                     running    00:58
     └ ⟦grep: TODO in src/⟧
────────────────────────────────────────────────────────────────
   时间线　#1　11-20/37 · 跟随
  23:14:28 💬 我先看一下 locks.ts
  23:14:30 ⚙ ⟦read: src/utils/locks.ts⟧
  23:14:31 ↳ 120 lines
────────────────────────────────────────────────────────────────
 Tab 切焦点 · ↑↓ 选 step · PgUp/PgDn 翻时间线 · g/G 首/尾 · c 清空 · …
```

| 按键 | 动作 |
| --- | --- |
| **`⏎`** | **进入详情**：选中 step 的完整信息 + 全部事件（再按 `⏎`/`Esc`/`q` 返回列表） |
| `Tab` | 切换焦点：步骤 ↔ 时间线 |
| `↑` `↓` / `j` `k` | 按焦点移动：切 step / 滚动时间线 |
| `PgUp` `PgDn` | 翻页时间线（不改变焦点） |
| `g` / `G` | 时间线跳到首 / 尾（`G` 恢复「跟随最新」） |
| `Home` / `End` | 步骤列表跳到首 / 尾 |
| `c` | 清空活动记录 |
| `r` | 立即重绘 |
| `q` / `Esc` | 退出 |

### 详情视图（按 `⏎` 进入）

```
────────────────────────────────────────────────────────────────
 ◆ Subagent 详情 · #1                     running · 02:14 · 25 事件
────────────────────────────────────────────────────────────────
 step        1
 名称        implementer/feature-builder
 状态        running
 开始        2026/11/5 00:07:27
 耗时        00:02:14
 当前工具    ⟦bash: npm test -- locks⟧
 事件构成    工具 8 · 结果 8 · 文本 9
────────────────────────────────────────────────────────────────
 ▸ 全部事件　1-16/25
  00:07:02 💬 我先看一下 locks.ts
  00:07:03 ⚙ ⟦read: src/utils/locks.ts⟧
  00:07:04 ↳ 120 lines
────────────────────────────────────────────────────────────────
 ⏎/Esc 返回列表  ·  ↑↓ 滚动  ·  PgUp/PgDn 翻页  ·  g/G 首/尾
```

列表页的每个 step 只显示最近几行；详情页给**全部事件**（可滚动）与完整元信息。

> 详情视图里 `q` **只返回列表、不退出面板** —— 否则想返回时会把整个面板关掉。
> 要彻底退出请回到列表再按 `q`，或在详情里按 `Ctrl+C`。

**跟随模式**：新事件到达时自动贴到底部；一旦手动上滚就暂停跟随（标题显示范围而不再标「跟随」），按 `G` 恢复。

**自适应宽度**：底部按键提示放不下时从尾部丢项并补 `…`，不会截断成 `c 清空 ·...` 这种半截样式。

## 边界

- 活动记录**只在内存**，不落盘 —— 这是运行时可观测性，审计仍看 step log。
- 每个 step 保留最近 400 条事件、最多 20 个 step（FIFO 淘汰）。
- `session_shutdown` 时清理 widget，避免跨会话残留。
- 非 TUI 模式退化为一行文本摘要。
